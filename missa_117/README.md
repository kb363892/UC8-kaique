## 2. Sobre o projeto

O Mundo Disney é uma aplicação desenvolvida para apresentar informações sobre personagens do universo Disney de forma simples, organizada e interativa.

##  6. Como executar o projeto

Explique passo a passo como outra pessoa pode executar seu projeto em outra máquina.

### Pré-requisitos

Para executar o projeto, é necessário ter um navegador de internet atualizado. Recomenda-se também utilizar um editor de código, como o Visual Studio Code, caso seja necessário modificar os arquivos.

Não é necessário instalar um servidor ou banco de dados para executar a versão básica do projeto.

### Passo a passo

* Passo 1 Baixar ou clonar os arquivos do projeto para o computador.
* Passo 2 Abrir a pasta mundo-disney no Visual Studio Code ou outro editor de código.
* Passo 3 Abrir o arquivo index.html no navegador.
* passo 4  A aplicação será carregada e o JavaScript realizará as requisições para a API.
* passo 5 Os dados dos personagens recebidos da API serão apresentados na interface.
